# email-marketing-studio

An email marketing studio for Kettlebird Tea, built with Claude Code. It plans a launch campaign for The Steep Club, writes the emails, personalizes them for each customer group, and sends practice emails safely.

## Related repositories

- [studio-kit](https://github.com/SobiaSarwar/studio-kit): the reusable parts of this studio, packaged as a Claude Code plugin (step 14).
- [client-two](https://github.com/SobiaSarwar/client-two): a made-up second client, Rise & Crumb bakery, used to test studio-kit (step 14).
